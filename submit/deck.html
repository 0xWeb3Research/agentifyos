the problem

An AI agent can reason, but it cannot buy.

Every API it wants sits behind a signup form built for a human. So agents work on a leash: somebody provisions keys in advance, and hopes.

the buyer

Cannot open an account

An agent that finds a useful API mid-task simply cannot use it.

the seller

Cannot sell a half cent

Billing costs more than the call earns, so it never ships.

both

Wrong shape entirely

Agents want thousands of tiny calls. Subscriptions want one big commitment.

Payments work fine. This is a market gap: there is nowhere a machine can shop.

08verifiable settlement

why algorand

The chain choice is a product decision.

What this market needsWhat Algorand givesWhy a user feels it
Prices that are actually prices USDC as a native asset $0.005 is 5000 units, exactly. No oracle, no drift.
Buyers who hold one thing Fee sponsorship in an atomic group Onboarding drops from two assets to one.
Fees that do not eat the sale A flat fee near zero A $0.002 call is viable. Elsewhere it is not.
Settlement inside a request Instant finality Payment fits inside the HTTP round trip.
Someone else to run the plumbing A hosted facilitator No key and no infrastructure of ours in the settlement path.

This project settled on another chain before, and the port took a chain abstraction rather than a rewrite. The reasons above are why Algorand is now the default.

revenue model

The publisher keeps 80%. We take 20%, and only on money that moved.

  • Every call is demand data nobody else holds.

  • Testnet only, by design.
